fundamental1-project · 어르신을 위한 음성 주문 키오스크를 그림으로

01 · 이게 뭐야

버튼 대신 "불고기 버거 세트 주세요"

작은 글씨와 복잡한 버튼이 어려운 어르신도, 점원에게 말하듯 키오스크에 말하면 주문이 된다.

02 · 왜 만들었어

전에는 "어디를 눌러야 하지?", 이제는 "말하면 된다"

03 · 어떻게 돌아가

귀 → 머리 → 입, 그리고 다시 귀

말 한 번이 지나가는 길. 화면은 백엔드가 정해 준 대로 그린다.

04 · 머리 속을 들여다보면

먼저 사전을 찾고, 모르면 친구에게 묻는다

규칙(사전)이 먼저 읽는다. 못 알아들은 말만 모델이 "표준 문장"으로 고쳐서 다시 사전에 넘긴다.

05 · 부품 지도

비유 ↔ 실제 폴더

👂🗣️
귀와 입 = frontend/React 화면. hooks/useVoice.js가 듣고, lib/tts.js가 읽어 준다. lib/screen.js가 그릴 화면을 고른다.
🧠
머리 = backend/FastAPI. services/dialog.py가 주문 단계(장소→메뉴→옵션→확인→쿠폰→결제)를, services/nlu.py가 말 뜻을 맡는다.
📝🏷️
받아쓰기·통역 = model/어르신 목소리로 다시 학습한 Whisper(/stt), 의도 파악 모델 2개(/nlu).
🗄️
장부 = PostgreSQL메뉴·옵션·쿠폰·주문·대화 기록. 처음 실행하면 seed.py가 메뉴를 넣는다.
🚚
배달 = k8s/, scripts/구글 클라우드(GKE)에 올리고, 문제가 생기면 rollback.sh로 되돌린다. 기록은 DEPLOY_LOG.md.
📋
팀 규칙 = AGENTS.md자기 폴더만 고치기, 브랜치 + PR, PR 내용은 노션 작업 로그로 자동 기록.
06 · 데이터는 어디로 가

"매운 닭 버거 두 개"가 장바구니에 들어가기까지

07 · 직접 해 보기

두 가지만 해 보세요

# 1) 내 컴퓨터에서 전체 실행 (Docker Desktop 필요, 모델 파일 약 1.3GB)
cp .env.example .env
bash model/scripts/fetch_model.sh && bash model/scripts/fetch_nlu_model.sh
docker compose up --build        # → http://localhost:3000

# 2) 대화 규칙 시험만 (DB·모델 없이 1분)
cd backend && pip install -r requirements-dev.txt && pytest -q   # 109개

먼저 열어 볼 파일: backend/app/services/dialog.py → backend/app/services/nlu.py → frontend/src/hooks/useVoice.js

08 · 조심할 곳

두 군데가 까다롭다

같은 "네"도 단계마다 뜻이 다르다. 세트 질문에서는 "세트로", 주문 확인에서는 "맞아요", 취소 확인에서는 "취소해 줘". 새 말을 추가하면 backend/tests/의 시험부터 돌린다.
마이크는 사람 목소리 안내와 싸운다. 에코 제거를 켜면 안내 중에 끼어들기가 안 되고, 말 시작을 너무 늦게 잡으면 "포장해"가 "보장해"가 된다. 그래서 1초 앞부터 녹음해 보낸다(useVoice.js, PR #37·#38).
그림은 모두 이 문서를 위해 직접 그렸습니다. 구조 분석: Understand-Anything 지식 그래프(.ua/knowledge-graph.json).
